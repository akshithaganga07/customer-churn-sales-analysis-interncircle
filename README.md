# Customer Churn / Sales Trend Analysis – InternCircle Task 3

## Overview
End-to-end analysis of an e-commerce transaction dataset to identify revenue trends, customer segments, product performance, and customer inactivity indicators.

## Features
- Data cleaning and duplicate handling
- Date extraction and feature engineering
- Revenue calculation
- Monthly sales trend analysis
- Customer-level revenue and order analysis
- High/Medium/Low customer segmentation
- Recency-based inactivity indicator
- Pivot table analysis
- Top-product revenue analysis
- Actionable business recommendations

## Tools
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab / Jupyter Notebook

## Dataset
Online Retail transaction data from the UCI Machine Learning Repository:
https://archive.ics.uci.edu/ml/machine-learning-databases/00352/Online%20Retail.xlsx

## Important Note on Churn
The dataset does not provide a verified churn label. Therefore, the notebook uses a 90-day purchase inactivity threshold as an illustrative churn/inactivity proxy. It is clearly identified as a proxy rather than confirmed customer churn.

## Outcome
The project demonstrates practical data-analysis skills by turning transaction-level data into revenue, customer-segmentation, and business insights.
